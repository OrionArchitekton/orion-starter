# Orion Astro MPA Islands Starter

Astro 7.4.13 MPA starter using Tailwind v4 OKLCH tokens, self-hosted `@fontsource-variable/*` typography, native CSS `@view-transition` navigation, `0 KB` client JavaScript on static routes, and one interactive island (`TokenPreviewIsland`) under `30 KB` total JS.

## Commands

```bash
npm install
npm run build
npm run preview
```

## Routes

- `/` (static, `0 KB` JS)
- `/architecture` (static, `0 KB` JS)
- `/playground` (interactive island via `@astrojs/preact` compat, `<30 KB` JS)
